Обзор проекта

Репозиторий содержит агентскую инфраструктуру и заготовки документации. Продуктовое приложение отсутствует, бэклог пуст.

Целевой стек

Java и Spring Boot, React и TypeScript с Vite, PostgreSQL. Maven Wrapper и Docker Compose будут добавлены вместе с приложением.

Расположение

  • 'AGENTS.md' и пакетные инструкции — правила работы.
  • 'prompts/', '.agents/skills/', '.claude/', '.codex/' — агентские материалы.
  • 'backlog/tasks/' — задачи; 'docs/specs/' — спецификации.
  • 'docs/' — документация; 'scripts/' — локальные проверки и генерация.

Сгенерировано из PROJECT_OVERVIEW.md командой npm run overview:build. Не редактируйте этот файл вручную; npm run overview:check проверяет его актуальность.
