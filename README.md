# Secreate-test

Агентский слой для проекта с целевым стеком Java и Spring Boot, React и TypeScript с Vite, PostgreSQL. Приложение отсутствует, продуктовый бэклог пуст.

Спецификации размещаются в `docs/specs/`; при запуске передайте агенту путь к выбранной спецификации и попросите выполнить `START_PROMPT.md`. Например: `codex "Прочитай START_PROMPT.md и выполни его для спецификации <путь-к-спецификации>"`. Можно передать и другой доступный путь.

Установка агентских инструментов: `npm ci`; проверка: `npm run check:agents`. Команды будущего приложения описаны в `docs/project/quality-checks.md`. Serena и MCP необязательны.
