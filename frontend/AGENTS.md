# Frontend

Цель: React, TypeScript и Vite. Приложение и package.json пока отсутствуют. После их появления используйте 'npm --prefix frontend ci', 'npm --prefix frontend run lint', 'npm --prefix frontend run build' и предусмотренные проектом тесты. Проверяйте состояния загрузки, ошибок и доступность интерфейса.
