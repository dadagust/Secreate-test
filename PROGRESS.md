# Состояние

Агентская инфраструктура перенесена для локальной работы; приложение отсутствует, продуктовый бэклог пуст. Целевой стек: Java / Spring Boot, React / TypeScript / Vite, PostgreSQL.

Проверка агентского слоя: `npm run check:agents`; результаты текущего запуска приводятся в отчёте. Проверки приложения подключаются после появления Maven Wrapper и frontend package.json.
