# Тестирование

Java-тесты используют Maven Wrapper и PostgreSQL через Testcontainers; они проверяют бизнес-правила, HTTP-доступ, конкурентные изменения и обмен с эмулятором. Frontend имеет lint, проверку запрета inline-стилей и браузерные сценарии. Агентский слой проверяется отдельно в корне.

Windows и Linux команды, предпосылки для браузера и изолированные lifecycle-проверки перечислены в [проверках качества](quality-checks.md). Подтверждённые результаты и оставшиеся проверки сопоставлены со спецификацией в [матрице](acceptance.md); нагрузочный профиль и исходные данные — в [отчёте NF08](performance.md).
