# Соглашения

Рабочие инструкции находятся в корневом и пакетных `AGENTS.md`. Код пишется на английском, документация и задачи — на русском. Изменения схемы PostgreSQL оформляются новой версионированной миграцией Flyway. Серверные проверки роли и области доступа обязательны для новых операций.

Визуальные значения и CSS frontend сосредоточены в `frontend/src/styles/`; компоненты используют семантические классы. Подробные правила, токены и требования к доступности — в [документации frontend](frontend.md). Публичные контракты обновляйте вместе с [API](api.md), а изменения архитектуры и ограничений — в источнике `docs/project/overview-source.txt` с последующим `npm run overview:build` и `npm run overview:check`.
