# Развёртывание

Проект поставляется для локального запуска. `compose.yaml` поднимает только PostgreSQL для запуска API, эмулятора и Vite на хосте. `compose.app.yaml` собирает и запускает все четыре сервиса; nginx раздаёт собранный frontend и проксирует `/api` к backend. `compose.performance.yaml` используется совместно с `compose.yaml` для ограниченного нагрузочного профиля.

Команды Windows, Linux, полного Compose, повторной загрузки демо и удаления тома приведены в корневом README. Для независимых стендов задавайте `COMPOSE_PROJECT_NAME` и свободные loopback-порты. Именованный том сохраняется при обычной остановке. Производственное развёртывание, TLS и управление секретами в объём локального демо не входят.
