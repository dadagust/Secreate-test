# Предсдаточный NF08: корректные полные страницы

## Сопоставимость и проверка страниц

Ранние JSON-отчёты сохранены без изменений. Аудит выявил, что прежний генератор выбирал страницы через `% 125`, а ответ списка с 0–19 строками мог считаться успешным. Поэтому прежние p95 списка и общий read p95 нельзя считать прямой базой сравнения: часть выборки могла включать неполные страницы. Новый результат получен с теми же лимитами и параметрами стандартного NF08; изменена только корректность выбора страниц и валидации ответов.

Перед нагрузкой генератор запросил фактический размер каждого используемого фильтра в PostgreSQL. Для Alice/`SUCCEEDED` найдено 1250 записей, выбраны страницы 0–61; для Bob/`FAILED` также найдено 1250 записей, выбраны страницы 0–61. Каждый ответ списка проверялся на ровно 20 элементов, ожидаемый номер страницы, бизнес-статус элементов и HTTP 200. Пустой, неполный или неверный ответ учитывается как ошибка профиля. Валидатор требует запросы, успешные ответы, отсутствие ошибок и ожидаемый HTTP-код отдельно у каждой группы `list`, `detail`, `create`, `patch`.

Полный машинный отчёт: [nf08-presale-2026-11-11.json](nf08-presale-2026-11-11.json). Предыдущие JSON и их происхождение не перезаписывались.

В измерении создано 638 заданий, скорость поступления составила 5.317 заданий/с. Очередь на границе измерения содержала 394 задания; после дополнительного окна все измерительные задания получили внешнее исполнение, а очередь опустела. Средняя скорость завершения за drain составила 7.462 задания/с. Полный drain приведён как фактический результат и инженерная цель улучшения, а не как нормативный порог спецификации.

## Среда

Запуск выполнен в Docker Desktop/WSL2 Linux kernel 6.6.87.2. Версии: Docker 29.2.1, Compose 5.7.0, Temurin 21.0.13, Maven Wrapper 3.10.0, PostgreSQL 17.11, Node 24.22.1 и npm 11.12.1. Суммарные квоты: backend 1.7 CPU/2304 MiB, PostgreSQL 0.2 CPU/1536 MiB, эмулятор 0.1 CPU/256 MiB. Генератор работал вне квот; браузер во время замера не запускался. Все искусственные режимы эмулятора перед замером сброшены и перепроверены.
