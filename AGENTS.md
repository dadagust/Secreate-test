# AGENTS.md

Правила для всех агентов. Целевой стек: Java / Spring Boot, React / TypeScript / Vite, PostgreSQL. Приложение пока отсутствует. Корневой package.json обслуживает только агентские инструменты. Перед работой в пакете прочитайте его AGENTS.md.

## Источники и уровни

Инструкции пользователя имеют приоритет. Проверяйте факты по коду и конфигурации, затем тестам и документации; не выдавайте планы за работающие возможности. Документация и задачи на русском, код на английском.

SMALL: локальное изменение без контрактов, зависимостей, конфигурации и архитектурных решений; осмотр, изменение, соразмерная проверка, diff и отчёт. STANDARD: связная фича или исправление; нужна задача с критериями и планом. LONG: несколько этапов, архитектура, миграции или несколько пакетов; нужны декомпозиция, WORKLOG и контрольные точки.

## Порядок

Изучите Git-статус и относящиеся инструкции и код. Для STANDARD/LONG создайте задачу Backlog.md с критериями приёмки, планом и способом проверки; переведите в In Progress. Реализуйте, проверьте, просмотрите diff, обновите документацию, отметьте критерии и результат, затем Done. Для LONG фиксируйте контрольные точки в WORKLOG.md и заметках задачи. Явно сообщайте непроверенные вещи. При ревью проверяйте требования, контракты, безопасность, регрессии и доказательства проверок; перед завершением сверяйте каждый критерий с результатом.

## Восстановление контекста

После сжатия или передачи прочитайте PROJECT_OVERVIEW.md, PROGRESS.md, активную задачу (npm run backlog -- task list -s "In Progress" --plain), WORKLOG.md, git status и git diff, затем инструкции затронутых пакетов. Не затирайте чужие изменения. При неоднозначности продолжайте независимую работу и уточняйте существенные решения.

## Проверки и Git

Запустите npm run check:agents. После появления приложения используйте команды из package AGENTS.md; модульную архитектуру проверяйте Spring Modulith. Не меняйте lock-файлы вручную. Не коммитьте, не отправляйте изменения и не уничтожайте чужие изменения без указания пользователя. Секреты не записывайте в Git или отчёты. Skills редактируются в .agents/skills и синхронизируются npm run skills:sync. Serena и MCP необязательны.
